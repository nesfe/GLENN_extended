# NASA Glenn FoilSim 3D PRO Extended

> **Вычислительный аэрогазодинамический комплекс нового поколения, основанный на концепциях NASA Glenn FoilSim & EngineSim.**

Современный интерактивный симулятор аэродинамики крыла и механики полета, объединяющий численное моделирование методом дискретных вихрей (Panel Method), трехмерную визуализацию в виртуальной аэродинамической трубе на WebGL, расчет сжимаемости, волнового и индуктивного сопротивления, а также акустический синтезатор обтекания в реальном времени.

---

## 🚀 Основные возможности

### 1. Вычислительная аэродинамика и физические модели
- **Численный панельный метод (Panel Method)**:
  - Решение уравнений потенциального обтекания профиля методом распределенных вихревых и источниковых панелей (метод Гесса-Смита).
  - Точный расчет локальных скоростей и эпюры распределения коэффициента давления $C_p(x/c)$.
  - Поправки на сжимаемость потока по Прандтлю-Глауэрту и Карману-Тьену с вычислением критического числа Маха $M_{crit}$.
- **Теория несущей линии Прандтля для 3D-крыла**:
  - Учет удлинения ($AR$), сужения ($\lambda$), угла стреловидности ($\Lambda$), геометрической крутки (washout $\epsilon$) и $V$-образности ($\Gamma$).
  - Индуктивное сопротивление $C_{Di}$ с поправкой коэффициента Освальда $e$.
  - Распределение циркуляции $\Gamma(y)$ и подъемной силы по размаху.
  - Моделирование законцовок крыла (уинглов / winglets).
- **Срыв потока и послесрывные режимы**:
  - Модель отрыва Кирхгофа-Гельмгольца с динамическим ростом толщины вытеснения пограничного слоя и индикацией точки отрыва.
- **Эффект Магнуса**:
  - Моделирование вращающегося цилиндра Флеттнера с расчетом подъемной силы и лобового сопротивления в зависимости от скорости вращения (об/мин).

### 2. Интерактивная 3D Аэродинамическая труба (Three.js WebGL)
- **Визуализация потока**:
  - Линии тока (Streamlines) с динамическими частицами дымовой визуализации.
  - Концевые вихри Прандтля (Wingtip Vortices), срывающиеся с законцовок крыла.
  - Векторы аэродинамических сил в центре давления: подъемная сила ($L$), сопротивление ($D$) и результирующая сила ($R$).
  - Цветовая карта распределения давления $C_p$ по поверхности крыла (Rainbow, Jet, Plasma, Thermal).
  - Сверхзвуковой конус Маха / ударная волна Шлирена при $M \ge 1.0$.
  - Каркасный режим (Wireframe) и переключение ракурсов камеры (Изометрия, Профиль, План, Законцовка).
- **Виртуальная трубка Пито-Прандтля**:
  - Интерактивный зонд измерения полного, динамического и статического давления, локальной скорости и локального числа Маха в любой точке 3D-пространства потока.

### 3. Инженерный 2D-анализ профиля
- Отображение теоретического контура профиля, хорды, средней линии кривизны (Camber line) и центра давления $X_{cp}$.
- Векторная эпюра нормальных сил разрежения/давления вдоль верхней и нижней поверхностей.
- Визуализация толщины пограничного слоя $\delta^*(x)$ и точки ламинарно-турбулентного перехода.

### 4. Многосредовые планетарные атмосферы
- **Земля (Earth ISA)**: Международная стандартная атмосфера от 0 до 25 000+ м (тропосфера, стратосфера).
- **Марс (Mars)**: Разреженная углекислотная атмосфера (низкое давление $\sim 610$ Па, скорость звука $\sim 240$ м/с, актуально для БПЛА класса *Ingenuity*).
- **Венера (Venus)**: Сверхплотная атмосфера ($\approx 93$ атм, плотность $65$ кг/м³).
- **Титан (Titan)**: Криогенная метано-азотная атмосфера с высокой плотностью ($5.4$ кг/м³) и низкой температурой ($94$ K).
- **Гидродинамика (Water)**: Несжимаемая водная среда для подводных крыльев (фойлов) и гребных винтов.
- **Пользовательская среда**: Ручной ввод плотности и скорости звука.

### 5. Механика полета и Силовая установка
- Поддержка различных типов двигателей:
  - **ТРДД** (Турбовентиляторный двухконтурный)
  - **ТРД** (Турбореактивный)
  - **Поршневой винтовой** (Авиация общего назначения)
  - **Электрический привод** (e-Aviation / БПЛА)
  - **Жидкостный ракетный двигатель** (ЖРД)
- Расчет летно-технических характеристик:
  - Скорость сваливания $V_{stall}$ на 1G
  - Наивыгоднейшая скорость планирования $V_{bg}$ и максимальное аэродинамическое качество $(L/D)_{max}$
  - Скорость минимального расхода мощности (максимальной продолжительности)
  - Максимальная скороподъемность $V_y$ и угол набора высоты
  - Практический потолок $H_{service}$
  - Тяговооруженность ($T/W$) и баланс располагаемой/потребной тяги

### 6. Аэродинамические поляры и Графики (Chart.js)
- Инвертированная эпюра $C_p(x/c)$ по верхней и нижней дужкам.
- Поляра Лилиенталя $C_L(C_D)$ с касательной максимального качества $(L/D)_{max}$ и текущей рабочей точкой.
- Кривые $C_L(\alpha)$ и $5 \cdot C_D(\alpha)$ от угла атаки.
- Распределение циркуляции $\Gamma(y)$ по размаху в сравнении с эллиптическим идеалом.

### 7. Синтезатор звука аэродинамической трубы (Web Audio API)
- Реалистичный процедурный генератор звука:
  - Шум набегающего воздушного потока (розовый шум с динамической полосовой фильтрацией по скорости и напору $q$).
  - Низкочастотный рокот и вибрация при срыве потока (Stall Buffet).
  - Акустический эффект сверхзвукового перехода (Sonic Boom).

### 8. Импорт и Экспорт
- **Импорт**: Drag-and-drop или загрузка профилей в форматах **AutoCAD .DXF** и **Selig / Lednicer .DAT**.
- **Экспорт 3D-модели**:
  - **.OBJ** — полигональная сетка крыла для CAD/CAM систем (Blender, SolidWorks, FreeCAD).
  - **.STL** — готовый файл для 3D-печати.
- **Экспорт данных**:
  - **.CSV** — аэродинамическая поляра и коэффициенты для Excel / MATLAB / Python.
  - **.DAT** — нормализованные координаты профиля Selig.
  - **.JSON** — полное состояние симуляции для сохранения и обмена пресетами.

## 🛠 Технологический стек

- **Ядро и UI**: React 19, TypeScript, Vite
- **Стилизация**: Tailwind CSS v4, Glassmorphism UI
- **3D Графика**: Three.js (WebGL, BufferGeometry, OrbitControls)
- **Графики**: Chart.js, react-chartjs-2
- **Аудиодвижок**: Web Audio API (розовый шум, BiQuadFilters, субгармонические осцилляторы)
- **Иконки**: Lucide React
- **Среда выполнения**: Bun / Node.js

### Запуск из исходного кода и разработка

#### Требования
- Установленный [Bun](https://bun.sh/) (рекомендуется) или Node.js (v18+)

#### Установка зависимостей
```bash
bun install
```

#### Запуск веб-версии в режиме разработки
```bash
bun dev
```
Откройте браузер по адресу: `http://localhost:3000`

#### Запуск десктопного приложения Electron
```bash
bun run electron:start
```

#### Сборка Windows .EXE приложения
```bash
bun run electron:build:win
```
Собранный портативный `.exe` будет создан в каталоге `release-builds/`.

#### Сборка веб-версии (HTML/JS)
```bash
bun run build
```
Готовые оптимизированные файлы будут скомпилированы в директорию `dist/`.
