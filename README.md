# GLENN Extended · Rust

[![Build, test and release](https://github.com/nesfe/GLENN_extended/actions/workflows/build-release.yml/badge.svg)](https://github.com/nesfe/GLENN_extended/actions/workflows/build-release.yml)

Нативная аэродинамическая лаборатория с русскоязычным интерфейсом. Полностью на Rust: без Node.js, Electron и встроенного браузера. Проект вдохновлён учебными симуляторами NASA Glenn; не является официальным продуктом NASA.

## Скачать

Готовые программы: **[GitHub Releases](https://github.com/nesfe/GLENN_extended/releases/latest)**.

| Платформа | Файл | Запуск |
|---|---|---|
| Windows 10/11 x64 | `windows-x86_64.exe` или `.zip` | Запустить EXE; установка не нужна |
| Linux x64, glibc ≥ 2.35 | `linux-x86_64.tar.gz` | Распаковать, запустить `./glenn-extended` |
| macOS Apple Silicon | `macos-aarch64.zip` | Распаковать приложение `.app` |

Шрифты, иконка и пресеты встроены. Требуется графический драйвер с OpenGL. Linux использует системные X11/Wayland, ALSA и xdg-desktop-portal для файловых диалогов. Windows/macOS бинарники не имеют коммерческой подписи / notarization. Контрольные суммы находятся в `SHA256SUMS.txt`.

## Возможности

- Панели Гесса–Смита с условием Кутты, Cp верхней/нижней поверхности и интегральными силами.
- Инженерные модели конечного крыла, сопротивления, срыва и эффекта Магнуса.
- NACA 4, NACA 230xx, сверхкритический параметрический профиль, клин, двояковыпуклый, пластина, цилиндр, импортируемые профили.
- Крыло с сужением, стреловидностью, круткой, поперечным V и законцовками; закрылки и предкрылки.
- Земля ISA до 80 км, Марс, Венера, Титан, вода и пользовательская среда; 10 стартовых пресетов.
- Нативная интерактивная 3D-проекция, цвет Cp, сетка, иллюстративные линии тока и вихри, силы, зонд, конус Маха; процедурный звук.
- 2D-сечение, Cp, поляра, CL(α), CD(α), нагрузка и циркуляция по размаху.
- Оценки сваливания, планирования, набора и потолка; модели пяти типов двигателя.
- Импорт DAT/Selig/Lednicer и ASCII DXF POLYLINE/LWPOLYLINE; экспорт CSV, DAT, JSON, OBJ и замкнутого STL.
- Автосохранение; загрузка JSON v2. Координаты экспортированной сетки в **метрах**.

Ограничения моделей и единицы описаны в [NUMERICS.md](docs/NUMERICS.md). Это учебная модель с инженерными приближениями, а не вязкий 3D CFD-решатель. Исторические пресеты не являются проверенными цифровыми моделями указанных самолётов.

## Интерфейс

На широком экране параметры находятся слева; при ширине меньше 1000 логических точек — на вкладке «Параметры». Длинные панели имеют собственную прокрутку. Вкладки разделяют трубу, профиль, графики, полёт, файлы и описание модели.

- Перетаскивание 3D-вида — поворот; колесо — масштаб; «Вписать» — восстановление.
- `Ctrl+O` / `Cmd+O` — импорт; `Ctrl+S` / `Cmd+S` — сохранить JSON.
- `Ctrl+` плюс/минус и `Ctrl+0` — масштаб интерфейса / сброс.
- Файлы DAT, DXF и JSON можно перетащить в окно.
- Число рядом со слайдером доступно для ручного ввода.

## Сборка

Установите Rust через rustup. Версия инструментов зафиксирована в `rust-toolchain.toml`; зависимости — в `Cargo.lock`.

Ubuntu/Debian:

```sh
sudo apt-get install build-essential pkg-config libasound2-dev libudev-dev \
  libx11-dev libxi-dev libxrandr-dev libxcursor-dev libxinerama-dev libxkbcommon-x11-0 libgl1-mesa-dev
cargo run --locked --release
```

Windows: Rust MSVC и Visual Studio Build Tools с компонентом C++ Desktop. macOS: Xcode Command Line Tools. Затем `cargo build --locked --release`. Исполняемый файл появится в `target/release/`.

```sh
cargo fmt --all -- --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked --all-targets
```

Архитектура и правила расширения: [ARCHITECTURE.md](docs/ARCHITECTURE.md). Обзор исходного проекта и исправлений: [AUDIT.md](docs/AUDIT.md).

## Автоматические сборки и релизы

GitHub Actions проверяет форматирование, Clippy и тесты, собирает Windows x64 / Linux x64 / macOS ARM64 и сохраняет архивы как artifacts. Linux также запускает программу в Xvfb и снимает каждую вкладку плюс окно с масштабом 150%.

После успешных проверок всех платформ push в `main` **автоматически публикует версию из Cargo.toml**, если она ещё не выпущена. Для следующего релиза обновите `version`, `Cargo.lock` и `docs/RELEASE.md`, затем отправьте commit в `main`. Ручной тег `vX.Y.Z` тоже поддерживается; он обязан совпадать с версией пакета. Существующие опубликованные релизы не перезаписываются. Дополнительные секреты не нужны: используется ограниченный `GITHUB_TOKEN`.

Сначала создаётся draft, затем загружаются все архивы и SHA-256; только после этого релиз публикуется. Ошибка проверки или сборки любой платформы блокирует выпуск.
