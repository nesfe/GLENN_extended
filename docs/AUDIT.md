# Обзор версии 2.0.0

База: `34cc61ee63892f1039f60bdbd4793ba1e395357d`.

Проект имел широкий набор демонстрационных функций и удачное начальное разделение физических моделей. Однако качество реализации не соответствовало заявленной точности. Выпускать его как проверенный инженерный комплекс было преждевременно.

| Приоритет | Наблюдение | Решение v3 |
|---|---|---|
| Высокий | `panelMethod.ts`: условие Кутты находится в строке N, но `solveLinearSystem(A, rhs, N)` использует только первые N строк и столбцов. | Полная система Hess–Smith, тест давления на задней кромке. |
| Высокий | `cpUpper` берётся с конца контура, то есть повторяет нижние панели. Нормали противоречат ориентации контура. | Однозначная ориентация и независимые диапазоны поверхностей; тест симметрии. |
| Высокий | ISA выше 20 км использует ошибочный знак степени: давление растёт с высотой. | Интегрирование слоёв с непрерывными базовыми давлениями. |
| Высокий | DAT/DXF могут давать разные длины массивов; генератор индексирует lower по длине upper. DXF разделяется по знаку y. | Разбиение по порядку контура, независимая интерполяция и валидация. |
| Высокий | Сверхзвуковая формула Пито не даёт правильного отношения p02/p1. | Соотношение Рэлея; тест при M=2 и непрерывности при M=1. |
| Средний | `CLmax` подменён текущим `CL`; поиск скорости использует другую тягу, чем текущий режим. | Максимум поляры и единая функция тяги. |
| Средний | TSFC по умолчанию 0,65 используется как кг/(Н·с); топливо ряда пресетов превышает полную массу. | Явные единицы, корректные пресеты, миграция старых проектов с уведомлением. |
| Средний | Нагрузка по размаху не нормирована на lift и не допускает отрицательных значений. | Подписанная нагрузка, тест интеграла. |
| Средний | Весь state запускает решатель; графики многократно собирают и решают одну геометрию. | Отделение View; кеш геометрии и двух базисных решений. |
| Средний | Главное React-представление — 1587 строк; fixed/sticky элементы и многоколоночная компоновка затрудняют работу на небольших окнах. | Нативные панели, вкладки, прокрутка, тесты прямоугольников и снимки окон. |
| Средний | Нет тестов, CI, автоматического выпуска; Electron поставляет браузер вместе с приложением. | Rust, тесты, матрица Windows/Linux/macOS и публикация после проверок. |

В v3 также сняты неподтверждённые заявления о точной CFD, решении полной несущей линии и воспроизведении конкретных сертифицированных самолётов. Названия исторических пресетов сохранены для ориентира, не как утверждение об их валидации.
