# План развития аэродинамической трубы

Исходная версия — 4.0.0-beta.3. Результаты каждого этапа и команды проверок записываются в [дневник](DEVELOPMENT_LOG.md). Выпуск должен сохранять обычную графику WGPU и открывать существующие проекты и расчёты.

| Этап | Проблема и изменение | Как принимается результат |
|---|---|---|
| Геометрия | Параметрическое крыло в быстрой трубе получает поле из одного сечения. Для STL сохранять треугольники, масштаб и собственное трёхмерное поле. Дать открыть STL, запустить продувку и вернуться к параметрическому крылу прямо в трубе. Использовать существующие камеру, освещение, материалы и линии WGPU. | Открыть ЦАГИ через диалог и перетаскивание, проверить 9408 граней, единицы, сохранённое поле и отсутствие сил от другого крыла. Переключение вкладок не запускает расчёт заново. |
| Сжимаемое течение | Встроенное сечение ограничено M=0,3. Ввести консервативный перенос массы, импульса и полной энергии, уравнение состояния газа, вязкие напряжения, теплопроводность и условие прилипания. Для STL необходим пространственный решатель. Силы и зоны обратного течения брать из того же расчёта. | Однородный поток, сохранение, ударная труба, вязкий тест и проверка отрыва по полю. Проверять M, Re, устойчивость и чувствительность к сетке. Сечение и полный объём валидируются отдельно. |
| Точность | Ранее сетка теряла тонкое крыло. Входной контроль замкнутости, масштаб, стенка body и checkMesh обязательны. Для количественных результатов нужны слои у стенки, распределение y+, контроль невязок и изменения нагрузок, сравнение минимум трёх сеток. | Записывать конкретные условия, модель турбулентности, размер сетки и погрешность для сил, давления и точки отрыва. Сопоставлять с открытой измеренной полярой и поверхностным давлением при совпадающих M и Re. До сравнения статус точности остаётся открытым. |
| Быстродействие | Изменяющиеся подписи сдвигали сцену, публикации поля прерывали трассировку. Сохранять законченные кадры и отменять только устаревшие задания. Измерять стоимость шага решателя, трассировки, подготовки карты и кадра отдельно. Кешировать неизменившиеся данные. | Замеры до/после на одной модели, сетке и машине. Проверять поля и нагрузки при одинаковом расчётном времени, задержку UI, паузу, несколько последовательных изменений параметров. |
| Обзор | Фиксированная высота сцены и плотная рейка скрывают крыло. Увеличить видовую область относительно окна, дать раздельно изучать модель, линии и срез. Карта требует единиц, шкалы, значения под курсором и понятного положения плоскости. | Проверить окно 800×600 и широкое окно на ЦАГИ. Модель, локальный дефицит скорости и положение среза должны читаться. Пропуски выборки остаются пропусками. |
| Результаты | Одно значение силы не показывает установление. Читать историю сил и невязок из журналов OpenFOAM. Добавить оси, единицы и различать время URANS и итерации SIMPLE. Далее — поверхностное давление и Cp, коэффициенты при введённой опорной площади, серия углов и экспорт результатов. | Сверить графики с файлами loads и журналом решателя. Проверить неполный расчёт, старый формат, направление потока и единицы. |
| Авторство и поставка | История и виджет GitHub ранее расходились. Проверять авторов, коммиттеров и подписи во всех публичных ветках и тегах, затем отдельно виджет. | Автор работы nesfe. При чистой истории и устаревшем виджете сохранить свидетельства для GitHub Support. Проверять реальные комплекты Windows/Linux перед релизом. |

### Состояние на 19 ноября 2026

STL открывается в обычной трубе. Для газа есть встроенный двумерный решатель и объёмные стационарный и нестационарный решатели. Реализованы графики, площадь для пересчёта сил, сравнение запусков и экспорт. Снимки, численные испытания и наблюдаемая чувствительность коэффициентов к сетке перечислены в VALIDATION.md и DEVELOPMENT_LOG.md. Проверка точности сопротивления и положения отрыва по всему рабочему диапазону остаётся открытой. История Git и статистика API подтверждают авторство nesfe, устаревший публичный виджет GitHub отслеживается отдельно.

### Полноценный выпуск 4.0.0

Сверить расчёты сечения на 64 и 96 ячейках и контрольный расчёт ЦАГИ на 3000 итераций. Для наклонного потока использовать одно направление входной скорости в проекции сил, коэффициентах и поиске обратного течения. Добавить переход к измеренному максимуму обратной скорости в объёмном поле, просмотр сил в ветровых осях и просмотр конца истории без начального переходного процесса. Проверить прежние CSV-столбцы и открытие сохранённого случая. Собрать Windows и Linux, выполнить комплектные продувки после распаковки, опубликовать обычный релиз и сверить контрольные суммы.
