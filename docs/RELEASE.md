# GLENN Extended 4.0.0-beta.3

Исправление продувки тонких STL и нестабильного отображения 3D-сцены.

- Исправлена потеря крыла при построении сетки OpenFOAM: сгущение учитывает толщину тела. Расчёт пустой трубы и открытие такого старого результата блокируются.
- Добавлена проверка загруженной модели «ЦАГИ 846-14 (без прорезей)» в Windows/Linux CI. Файл включён в папку `models`; единицы этой модели — метры.
- Импортированная модель показана перед настройками, доступны вписывание и ракурсы. Кнопка открытия STL есть прямо на вкладке «Объёмная CFD».
- Выборка поля плотнее возле модели; срез проходит через её середину, линии прослеживаются по рассчитанному полю возле крыла. Маркеры движутся со скоростью из CFD.
- Устранены прыжки обычной 3D-трубы при перерасчёте, отмена незавершённой трассировки каждым новым кадром и исчезновение сцены при неподдерживаемом режиме.
- Полный архив Windows/Linux включает решатель. Распакуйте всё содержимое: папка `runtime` должна оставаться рядом с приложением.

Объёмная CFD остаётся несжимаемым расчётом. Встроенный быстрый решатель обычной
трубы по-прежнему ограничен малым числом Маха и низким расчётным Re; выше M=0,3
сцена показывает подписанную панельную оценку. Новый сжимаемый решатель в этот
выпуск не включён. Работоспособность импорта и продувки не означает подтверждённую
точность сил: сходимость и независимость от сетки проверяются для конкретного случая.

Стабильным релизом остаётся 3.2.0. Лицензии комплектных компонентов —
`docs/THIRD_PARTY.md`, контрольные суммы — `SHA256SUMS.txt`.
