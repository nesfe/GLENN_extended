# Запуск GLENN Extended

Скачайте архив для своей системы из [GitHub Releases](https://github.com/nesfe/GLENN_extended/releases/latest). Приложение работает локально; для расчётов подключение к сети не требуется.

- Windows 10/11 x64: запустите EXE или распакуйте ZIP. Коммерческой цифровой подписи нет.
- Linux x64: распакуйте TAR.GZ и запустите `./glenn-extended`. Нужны ALSA, X11 либо Wayland и графический драйвер с Vulkan или OpenGL. На Ubuntu: `sudo apt install libasound2 libxkbcommon-x11-0 libvulkan1 mesa-vulkan-drivers` (в новых выпусках пакет ALSA может называться `libasound2t64`).
- macOS Apple Silicon: распакуйте ZIP и откройте `.app`. Приложение подписано локальной ad-hoc подписью, без Apple notarization; первый запуск может потребовать разрешения в настройках конфиденциальности и безопасности.

При отсутствии поддерживаемого графического адаптера запуск завершится ошибкой инициализации графики. На Linux программный Vulkan-драйвер Mesa позволяет запускать приложение без отдельной видеокарты.

Готовые сборки включают звук, поэтому на Linux им нужна библиотека ALSA. Если собираете из исходников и звук не нужен, `cargo build --release --no-default-features` снимает зависимость от `libasound2-dev`; флажок «Звук» в этом случае сообщит, что сборка выполнена без звукового бэкенда. Расчётная часть и форматы файлов от этого не меняются.

`SHA256SUMS.txt` содержит контрольные суммы файлов релиза. Пример проверки на Linux: `sha256sum -c SHA256SUMS.txt` из папки с загруженными файлами.
